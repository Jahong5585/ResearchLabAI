## Цель проекта

Создать локальную исследовательскую лабораторию с ИИ-агентами, способную:

- искать научные статьи;
- анализировать PDF-документы;
- строить базу знаний;
- помогать в написании диссертаций;
- координировать работу нескольких ИИ-агентов;
- отображать процесс работы агентов;
- в будущем получить полноценную 3D-визуализацию лаборатории.
